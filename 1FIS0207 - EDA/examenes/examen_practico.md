# Examen Practico 01

1. **PREGUNTA 01:** [(VER SOLUCION)](/examenes/EP_ejercicio01.py)
   El banco “Mi Crédito Seguro” aprueba préstamos bajo las siguientes condiciones:
   • El cliente debe tener más de 25 años.
   • Debe contar con al menos 2 años de experiencia laboral.
   • Si el cliente gana más de \$2500 mensuales, el crédito se aprueba automáticamente.
   • Si gana entre \$1500 y \$2500, solo se aprueba si no tiene deudas.
   • Si gana menos de \$1500, el crédito no se aprueba.

   > Muestra un mensaje indicando si el crédito es Aprobado, Aprobado con condiciones, o Rechazado.

2. **PREGUNTA 02:** [(VER SOLUCION)](/examenes/EP_ejercicio02.py)
   Dado un número entero N, imprime en consola un triángulo numérico invertido como el siguiente ejemplo (para N = 5):

   > 12345
   > 1234
   > 123
   > 12
   > 1

3. **PREGUNTA 03:** [(VER SOLUCION)](/examenes/EP_ejercicio03.py)
   Un número se dice espejo si al invertir el orden de sus dígitos se obtiene el mismo número (por ejemplo: 121, 4554, 9009).

   > Solicita un número entero positivo N y muestra todos los números espejo menores o iguales a N. Además, indica cuántos números espejo se encontraron.

4. **PREGUNTA 04:** [(VER SOLUCION)](/examenes/EP_ejercicio04.py)
   Una compañía guarda las ventas que ha generado en un sistema de información. Los datos se encuentran almacenados en un arreglo con el código del cliente, otro arreglo con monto de la venta y un arreglo del estado de la venta (Por Pagar, Pagado).

   > Se le solicita:
   >
   > - Dado el código de un cliente, determinar la cantidad de ventas que ha generado.
   > - Dado el código de un cliente, determinar el porcentaje de ventas que se encuentran pendientes de pago.
